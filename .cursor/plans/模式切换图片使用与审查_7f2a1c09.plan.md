### [Draft: 初始架构]

- 效果图（`mock_*` / `mode_switch_*`）只对照验收；正式运行只拷 `slice_*`（或质量更好的 `ui_*`）进 `Texture2D`。
- 产品流：局外 SettingsBar `ModeToggle` →（推荐）`ModeSwitchPanel` → `BtnLevel`/`BtnEndless` → `UIHudTransition.UserRequest*` → `GameMode.TrySetMode` → HUD 先退后进。
- 选中态用脚本换 Sprite（`*_on` / `*_selected`）；局内灰显用 disabled；入口旁用 TMP 显示「关卡/无尽」。

### [Iteration 1: 漏洞注入与重构]

1. **状态机**：对局中 `TrySetMode==false` 时若仍显示彩色 selected → 误导。需 disabled + 入口不可点。
2. **时序**：过渡中连点已由 `isTransitioning` 忽略；切图侧勿用 Button SpriteSwap 再叠一套「Pressed=选中」造成与脚本抢图。
3. **边界**：`ui_*` 与 `slice_*` 双套并存 → User 易拷错；旧 `ui_btn_mode_disabled` 是胶囊「关卡」文案，不能当圆形按钮灰态。
4. **过度设计**：不必再做整屏 mock 进运行时；模式芯片优先 TMP，不必强制新切图。

- **本轮发现**：disabled 形态错误；关卡常态若带烘焙字与选中语言不一致；`ui_endless_selected` 内嵌文字+勾与 `slice_*_on` 白描边两套语言。
- **本轮补丁**：白名单锁定 **slice 圆形套**；P0 重做 disabled + 统一旗标；选中态统一白描边或统一勾标。

### [Iteration 2]

- mock 要求入口旁即时文案「关卡/无尽」——仅靠 toggle 图标不够「当前选中哪」。
- 面板 mock 为木牌风；现有 `slice_panel` / `ui_panel` 仅为米色圆角板，缺立柱/标题「模式」——标题用 TMP 即可，不必重做整板。
- mock 关卡有青底芯片、无尽仅为浅灰裸字 → 可发现性不对称（见 §5 设计优化）。
- **退出**：3 轮内足够落地；残余见 §4 / §5。

## 1. 使用逻辑（产品）

### 1.1 玩家路径（局外）

```text
局外 MainLevelMode
  → 看见 SettingsBar 圆形按钮列 + 青圆 ModeToggle（换模式入口）
  → （推荐）点 ModeToggle → OpenModePanel → 木牌/米色面板
       → 点 BtnLevel 或 BtnEndless
  → UIHudTransition.UserRequestLevelMode / UserRequestEndlessMode
  → GameMode.TrySetMode（先 Current → Refresh → Changed）
       ├─ 成功：Neuron.Refresh + Changed → HUD 先退再进；按钮换 selected；TMP 芯片改「关卡/无尽」
       ├─ 同模式：短路，不播动画
       └─ 局内 IsPlaying：返回 false → 不切；入口/按钮保持灰或不可点
```

### 1.2 选中态 / 灰态怎么用图

| 状态 | 视觉 | 用图 |
|------|------|------|
| 局外·当前关卡 | BtnLevel = `_on`；BtnEndless = 常态；芯片「关卡」 | `slice_btn_level_on` / `slice_btn_endless` |
| 局外·当前无尽 | 反过来；芯片「无尽」 | `slice_btn_endless_on` / `slice_btn_level` |
| 过渡中 | 锁射线；忽略再点 | 可保持上一选中图，不必换 disabled |
| 局内对局 | ModeToggle / 面板按钮 `interactable=false`；换灰圆 | **圆形** `ui_btn_mode_disabled` |
| 入口可发现性 | 青圆换箭头与齿轮列同级；旁有模式文字 | 图标 `slice_icon_mode_toggle` + **TMP**（mock 关键） |

### 1.3 与 `UIHudTransition` 对应

| UI 动作 | 方法 | 切图副作用 |
|---------|------|------------|
| 开面板 | `OpenModePanel()` | 面板 CanvasGroup alpha↑；按 `GameMode.Current` 刷 selected |
| 选关卡 | `UserRequestLevelMode()` | TrySetMode→成功则换 Level selected + HUD 过渡 |
| 选无尽 | `UserRequestEndlessMode()` | 同上 |
| 关面板 | `CloseModePanel()` | 可选；切成功后建议自动关 |

字段侧（合并计划 §4.5/§4.7）：`levelNormal/Selected`、`endlessNormal/Selected`、`disabledSprite` 拖 Texture2D 白名单 Sprite；**推荐脚本换 Image.sprite**，Button Transition 用 **ColorTint**（不要 SpriteSwap 再管选中，避免与脚本打架）。

## 2. 使用明细（逐控件）

### 2.1 `ModeToggle`（SettingsBar 旁）

| 项 | 建议 |
|----|------|
| 挂在 | `Canvas/SettingsBar` 下（或与齿轮同级），对照 `mock_hud_*` / `mode_switch_in_settings_bar` |
| Image.sprite | Texture2D `ui_icon_mode_toggle`（源自 `slice_icon_mode_toggle`） |
| Button | Transition = **ColorTint**；Disabled 可换 `disabledSprite` |
| OnClick | `UIHudTransition.OpenModePanel()`（推荐）；无面板时可绑循环切换 API（若 Agent 提供） |
| 旁芯片 | 子物体 **TMP**：「关卡」/「无尽」；颜色可用青底白字小 pill（**两模式同容器**，见 §5） |

### 2.2 `ModeSwitchPanel` 底板

| 项 | 建议 |
|----|------|
| 挂在 | `Canvas/ModeSwitchPanel` → 子 Image |
| Sprite | `ui_panel_mode_switch` ← `slice_panel_mode` |
| Image Type | **Sliced**；Border 初值 24,24,24,24 |
| 标题「模式」 | **TMP**，勿烤进面板图 |
| 显隐 | CanvasGroup；默认 alpha=0 |

### 2.3 `BtnLevel` / `BtnEndless`

| 项 | BtnLevel | BtnEndless |
|----|----------|------------|
| 常态 Sprite | `ui_btn_mode_level` ← slice | `ui_btn_mode_endless` ← slice |
| 选中 Sprite | `ui_btn_mode_level_selected` ← slice_on | `ui_btn_mode_endless_selected` ← slice_on |
| 换图方式 | **推荐**：`UIHudTransition` 改 `levelBtnImage.sprite` | 同左 |
| Button Transition | ColorTint；**不要** SpriteSwap 定义 Selected=选中图 | 同左 |
| 文案「关卡/无尽」 | **子 TMP**（mock 面板下方文字）；勿依赖 `ui_*` 烘焙字 | 同左 |
| OnClick | `UserRequestLevelMode` | `UserRequestEndlessMode` |
| 可选勾角标 | 子 Image = `slice_badge_check`，仅当前模式显示 | 同左 |

### 2.4 选中态对比度（当前 slice 套）

- `_on` = 同色圆 + **白描边** → 在雪地上足够区分，符合「当前模式一眼可见」。
- mock 额外有 **勾角标** → 可选叠 `slice_badge_check`；**不要**同时用 `ui_btn_mode_endless_selected` 的内嵌勾+内嵌字。

### 2.5 Disabled（现状与目标）

- **旧版**（已替换）：灰胶囊「关卡」→ 禁止挂圆形 Btn。
- **现版（2026-07-15 已写入 TestImage）**：256×256 中性灰圆 + 浅色锁标、**无汉字**、四角透明 → 赋给 `disabledSprite` / 局内 ModeToggle。
