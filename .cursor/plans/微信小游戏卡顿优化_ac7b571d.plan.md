# 微信小游戏卡顿优化（逻辑正确性终稿）

## 结论

- 性能优化不得改变玩法语义；**§3.10 逻辑冻结清单**与 **§2.7/§2.8 不变量**为最高优先级。
- 关卡：WarmUp(300) → Refresh；无尽：WarmUp(80) → `OnBackToMenu()`。
- **关卡与无尽 `Place` 公式不同**，禁止混用。
- 现网已确认 Bug（本轮必须顺手修，否则优化后更易暴露）：
  1. `App.OnBackToMenu` 同步 GC 早于 PineGenerator.Spawn
  2. `whooshable` 未跳过 `IsDestroyed()` → Fever 毁树后仍可能 `Pass`+Whoosh
  3. `PineDestroyedEffect.Invoke("Kill")` 在回收复用后可能误杀新实例
  4. 裁剪若 `OnEnabled` 先开全 Renderer 而不立刻 Sync → Refresh 首帧闪数百棵树

## 2. 防 Bug 与逻辑不变量

### 2.1 池 / WarmUp

| 风险 | 强制做法 |
|------|----------|
| `Get+Kill` 预热 | 禁止；仅 `WarmUpInactive` |
| 池容器 | `List<T>` 尾部入/出；`OnDestroy` 可 `Remove(this)` |
| 预热副作用 | 不调 `OnEnabled`；显式关 Renderer；无尽 `enabled=false` |
| `Get` | `PurgeDestroyed` 后 Pop；Unity 已销毁则丢弃重试 |
| `OnDestroy` 且 `alive` | `alive=false` → `OnDisabled()` → `pool.Remove` → `base.OnDestroy()` |
| 双重入池 | `Kill` 仅 `alive==true` 时执行 |
| PineDestroyedEffect | 禁止 WarmUp |

### 2.2 刷树 / z

| 风险 | 强制做法 |
|------|----------|
| 行数上限挖空 | 游标只减已生成行数 |
| `z=-y*scale` | **禁止**（会破坏无尽叠画） |
| serial z | 见 §3.3；`OnBackToMenu` 重置 `pineSerial=0` |
| 删 ResetZ | 禁止半批；不再遍历四队列改 z |

### 2.3 裁剪 / Whoosh / Destroy

| 风险 | 强制做法 |
|------|----------|
| 裁剪 | 只动 Renderer；禁 `SetActive` |
| `Pass` | `forceVisible=true` 至动画结束（`passed>1` 或无尽 `passed<-0.5`） |
| 无尽 Whoosh | **仅** `CheckPines` 调 `Neuron.Whoosh()`；`Pass()` 内禁止 |
| `DestroyPine` | `OnDisabled` + `destroyed=true` + **`enabled=false`**；不入池；`CheckPines` 认 `IsDestroyed()` |
| NightMode | `!alive \|\| destroyed` → return |

### 2.4 RollingStone.KillAll

```csharp
static readonly List<RollingStone> killSnapshot = new List<RollingStone>();
public static void KillAll() {
  killSnapshot.Clear();
  killSnapshot.AddRange(stones);
  stones.Clear();
  for (int i = 0; i < killSnapshot.Count; i++)
    if (killSnapshot[i] != null) killSnapshot[i].Kill();
}
```

`OnDisabled`：`stones.Remove(this)`（先于 WarmUp 滚石）。

### 2.5 CleanPineQueue 空引用（第 6 轮）

静态 `Queue` 在域不重载/异常 Destroy 后可能含 **null/已销毁** 引用：

```csharp
private void CleanPineQueue(Queue<Pine> queue) {
  foreach (Pine item in queue) {
    if (item == null) continue;           // Unity 假 null
    item.Kill();
  }
  queue.Clear();
}
```

`CleanClosePines` 同理：Dequeue 后若 null 则 `continue` 不 Enqueue。

### 2.6 静态 / 事件 / GC 顺序

| 风险 | 强制做法 |
|------|----------|
| 关卡延迟 Refresh | Start：**Clean 四队列 → WarmUp → Neuron.Refresh()** |
| 无尽 Start | **WarmUp(80) 完成 → 再 `OnBackToMenu()`**（禁止先 Spawn 再 WarmUp） |
| `neurons[Event.X]` | 静态构造 **预建空 Chain**（每个 Event 一条） |
| Endless 无 OnDestroy | 补全，镜像关卡 |
| **BackToMenu GC 顺序** | `App` 禁止同帧 `GC.Collect`；`StartCoroutine` 下一帧 Collect；保证 PineGenerator `SpawnPines` 等同帧回调先完成 |
| Editor 域不重载 | `Get()` 前 `PurgeDestroyed` |

### 2.7 逻辑不变量（实现后必须恒真）

```
I1  alive ⇒ 不在 pool 中；pool 中对象 alive==false
I2  pool 内无重复引用；Get() 返回时 alive==true
I3  在 Queue 中的 Pine 必 alive==true（DestroyPine 例外：alive 仍 true 但 destroyed==true，仍在队列直至 Kill）
I4  Kill() 后：alive=false，Renderer 关，无尽 enabled=false，入 pool
I5  Place() 是 xy 唯一写入点（移动树必须经 Place）；CheckPines/Peek 只用 GetX/GetY
I6  关卡 z 公式与无尽 z 公式互不混用（§3.10）
I7  CheckPines 阈值与队列 while 条件与现网一致（§3.10）
I8  无尽 Neuron.Whoosh 仍由 CheckPines 在 Pass 之后调用，且每棵危险树每帧最多一次
I9  destroyed==true 的树：不得 Pass、不得 Whoosh、不得再触发 GameOver；仅可被队列推进后 Kill
I10 PineDestroyedEffect：任意时刻最多一个 pending Invoke；入池前必须 CancelInvoke
```

### 2.8 第 7 轮新发现（必修）

| # | 问题 | 证据 | 强制修法 |
|---|------|------|----------|
| A | **whooshable 不认 `IsDestroyed`** | [`PineGenerator.CheckPines`](Assets/EndlessRes/Scripts/Assembly-CSharp/PineGenerator.cs) 238–249：仅 `!IsPassed()`；Fever `DestroyPine` 后树仍进 whooshable，可再 `Pass`+`Neuron.Whoosh` | whooshable 循环加 `if (IsDestroyed()) continue;`（dangerous 已有，对称） |
| B | **`PineDestroyedEffect.Invoke("Kill")` 晚到** | [`PineDestroyedEffect`](Assets/EndlessRes/Scripts/Assembly-CSharp/PineDestroyedEffect.cs) `OnEnabled`→`Invoke("Kill", duration)`；若提前 Kill 回池再 `Get`，旧 Invoke 会 Kill **新一轮存活实例** | `OnDisabled`：`CancelInvoke(); system.Stop(true, true);`；禁止 WarmUp 该类型 |
| C | **裁剪首帧闪树** | 关卡 `OnEnabled` 现开 3 个 Renderer；Refresh 一次生成数百棵 | 方案二选一（选定 **C1**）：**C1** `OnEnabled` 只准备状态、**默认 Renderer 关**，`Place` 后或 `SpawnPines` 末/进入 dangerous 时 `SyncVisible`；**C2** Spawn 循环内每棵立刻 Sync（更碎） |
| D | **无尽 `OnEnabled` 未重开脚本** | Kill/WarmUp 会 `enabled=false`；现网 `OnEnabled` **不**设 `enabled=true` | `OnEnabled` 末尾 **`enabled = true`**（NightMode/Whoosh 动画依赖 Update） |
| E | **关卡 `RollingStone.Get()` 无 null 检查** | `GeneratePineLine`：`Recyclable<RollingStone>.Get().SetTargetY(y)` | `var s = Get(); if (s != null) s.SetTargetY(y);` |
| F | **DeferredCollect 重入** | 连续回菜单可叠多个协程 | 静态/实例 flag 或 `StopCoroutine` 后再开；同帧多次 BackToMenu 只预约一次 GC |
| G | **WarmUp 放大 NightMode 广播** | 无尽 Pine 覆写 `OnNightModeSwitched`，Awake 注册；WarmUp 80 棵常驻 Chain | early-out `!alive\|\|destroyed` **必须**；属可接受代价 |
| H | **struct Enumerator 勿 `IDisposable`** | 若实现接口，foreach 可能装箱 | 只提供 `MoveNext`/`Current`/`GetEnumerator()`，**不**实现 `IDisposable` |
| I | **关卡 `GetDistance` 随 Spawn 变化** | `SpawnPines` 中 `spawnY` 递减 → `PINE_PROBABILITY_MULTIPLIER` 变化 | **保持现网行为**，禁止为「稳定」缓存 GetDistance |

## 3. 实现规格

### 3.1 Recyclable（双边镜像）

见 §2.1；`WarmUpInactiveCoroutine(target, perFrame)` 只补 `max(0, target-PoolCount)`。

池根 `_RecyclablePoolRoot`：首次 WarmUp 时在场景内创建空物体，预热实例挂其下，本地 `(0,-9999,0)` 或统一关 Renderer。

### 3.2 Start 时序（写死）

**关卡 `PineGenerator`**

```text
Start:
  enabled = false
  StartCoroutine(InitLevelPines())

InitLevelPines:
  CleanPineQueue ×4                    // null-safe
  if Pine.PoolCount < 300:
    yield WarmUpInactive(300, 30/frame)
  if RollingStone.PoolCount < 8:       // Remove 修复后
    yield WarmUpInactive(8, 4/frame)
  Neuron.Refresh()                     // FinishLine(0) 先于 PineGenerator(2) 已 Awake
```

**无尽 `PineGenerator`**

```text
Start:
  init wd/swd; enabled = false
  StartCoroutine(InitEndlessPines())

InitEndlessPines:
  if Pine.PoolCount < 80:
    yield WarmUpInactive(80, 20/frame)
  OnBackToMenu()                       // 内含 Clean+serial=0+Spawn；勿 Neuron 事件
```

用户回菜单：`MenuPage` → `Neuron.BackToMenu()` → 各订阅者含 PineGenerator.Spawn；`App` **仅** 下一帧 GC。

### 3.3 无尽 z（替换 ResetZ）

```csharp
// PineGenerator 字段
static int pineSerial;

// OnBackToMenu 内（删 nextZ=0，改）:
pineSerial = 0;

// GeneratePineLine 内（删 nextZ/ResetZ）:
pineSerial++;
float worldZ = transform.position.z - (pineSerial % 1000) * 0.001f;
pine.Place(num4, y, worldZ);
```

### 3.4 Place 公式（第 6 轮 · 禁止混用）

**关卡**（保持现网 [`Pine.Place`](Assets/Scripts/Assembly-CSharp/Pine.cs)）：

```csharp
// 第三参 z 为深度偏移 bias，不是 world Z
public void Place(float x, float y, float zBias) {
  this.x = x; this.y = y;
  transform.position = new Vector3(x, y, 1f * y + zBias);
}
```

**无尽**（新增，与关卡不同）：

```csharp
public void Place(float x, float y, float worldZ) {
  this.x = x; this.y = y;
  transform.position = new Vector3(x, y, worldZ);
}
public float GetX() => x;
public float GetY() => y;
```

**迁移要求**：无尽 `CheckPines` / `CleanClosePines` / 队列 `Peek().GetY()` **全部**改 `GetX/GetY`；禁止混读 `transform.position`（除非 Place 同步保证一致，仍统一 API 防漏）。

### 3.5 无尽 SpawnPines（行数上限）

```text
targetY = camera.y - 12
cursor = generator.y
deficit = (cursor - targetY) / 0.3
maxLines = deficit > 20 ? 12 : 4
lines = 0
while cursor > targetY && lines < maxLines:
  GeneratePineLine(cursor)
  cursor -= 0.3
  lines++
generator.y = cursor
```

### 3.6 关卡裁剪（含防闪树）

- **选定 C1**：`OnEnabled` **不**打开 trunk/leaves/shadow（只设 size/color/`forceVisible=false`/`passed`）；`SetRenderersVisible` 专责开关。
- `Place` 之后或队列转入 dangerous 时 `SyncVisible`；coming 仅窗口内显示。
- `Pass()`：`forceVisible=true` 并开 bonus；动画结束 `forceVisible=false` 再 Sync。
- `SpawnPines` 结束后可再扫 coming 做一次窗口 Sync（可选，防漏）。

### 3.7 GC（防重入）

- 关卡：删 `Neuron.Refresh` 末尾 `GC.Collect`。
- 无尽：

```csharp
bool gcScheduled;
protected override void OnBackToMenu() {
  state = State.Menu;
  if (gcScheduled) return;
  gcScheduled = true;
  StartCoroutine(DeferredCollect());
}
IEnumerator DeferredCollect() {
  yield return null;
  gcScheduled = false;
  GC.Collect();
}
```

### 3.8 Neuron struct 枚举器 + Endless 预建链

**静态构造（无尽，对齐关卡）**：预建每个 `Event` 的空 `Chain`。

**OnDestroy（无尽新增）**：`neurons.Values` → `Remove(this)`。

**Enumerator**：`struct`；`MoveNext` 先推进 `_next`；**不**实现 `IDisposable`。

### 3.8b 无尽 CheckPines / Destroy 路径（第 7 轮）

```csharp
foreach (Pine whooshablePine in whooshablePines) {
  if (whooshablePine.IsDestroyed()) continue;  // 新增，对齐 dangerous
  if (!whooshablePine.IsPassed()) { ... }
}
```

`PineDestroyedEffect.OnDisabled`：

```csharp
CancelInvoke();
if (system != null) system.Stop(true, ParticleSystemStopBehavior.StopEmittingAndClear);
```

无尽 `Pine.OnEnabled` 末尾：`enabled = true;`
无尽 `Pine.OnDisabled` / `DestroyPine`：`enabled = false;`

### 3.10 逻辑冻结清单（禁止改数值/语义）

实现时 **不得修改** 下列行为（仅允许性能等价实现）：

| 区域 | 冻结内容 |
|------|----------|
| 关卡碰撞 | 死亡 `num4 < 0.0225f` → `EndRun`；擦边 `num4 < 1f` 且未 Pass |
| 关卡队列 | coming→dangerous：`GetY() > Skier.Y-0.3`；dangerous→whooshable：`GetY() > Skier.Y`；whooshable→pending：`GetY() > Skier.Y+1`；Kill：`GetY() > Camera.Y+10` |

| 无尽队列 | 阈值与现网 `CheckPines` while 条件一致（0.3 / player.y / wd / camera+10） |
| 关卡生成 | `spawnY` 步长 0.3；概率 `Parameters.*`；滚石概率独立 |
| 无尽生成 | Perlin+curve 公式不变；行距 0.3；`SPAWN_AHEAD=12` |
| 计分 | 关卡 `Pass`→`Neuron.Whoosh(points)`；无尽 `Pass`+CheckPines 分调 Whoosh |
| 续命 | `CleanClosePines` 距离阈值：关卡 `1.5f`，无尽 `2.25f` |
| Place | 关卡 `y+zBias`；无尽 `worldZ` 直接 — **不得统一成一个公式** |
